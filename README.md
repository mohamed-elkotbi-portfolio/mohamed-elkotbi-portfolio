# Mohamed ELKOTBI — Engineering Portfolio

A responsive, multi-page static website built with HTML, CSS and vanilla JavaScript. No framework, build process, paid hosting or backend is required.

## Pages
- `index.html` — homepage
- `about.html` — profile, experience and education
- `projects.html` — selected projects and case studies
- `skills.html` — engineering skills and tools
- `ideas.html` — ideas and innovation themes
- `contact.html` — contact details and email-compose form

## Before publishing — important personalization
1. Open `assets/main.js`.
2. Replace `YOUR_EMAIL@example.com` with your professional email address.
3. Replace `https://www.linkedin.com/in/YOUR-PROFILE/` with your actual LinkedIn profile URL.
4. In `contact.html`, update the visible location if needed.
5. Review all descriptions, dates, software proficiency and project summaries. Correct anything that does not exactly reflect your experience.
6. Add your own approved project images, CAD renders, diagrams and screenshots. Do not publish employer/customer confidential information.
7. Optional: replace the ME initials graphic in `about.html` with a professional portrait.

## Preview locally
Open `index.html` in a browser. For best results, use a local static server (for example VS Code Live Server).

## Free publishing with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new **public** repository named `mohamed-elkotbi-portfolio` (or use `YOUR-USERNAME.github.io` for a user site).
3. Upload all files and folders in this package. Keep `index.html` at the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
6. Wait for the deployment URL shown in the Pages settings. It will be a free `github.io` address.

## Contact form behavior
The contact form uses a `mailto:` link to open the visitor's email application. It does not store or transmit form submissions. A hosted form service or backend would be needed for direct submissions.
